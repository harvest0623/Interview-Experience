9. 声明一个乱序的数组，然后找出它的中位数
``` JavaScript
const arr = [9, 2, 7, 1, 5, 8, 3, 6, 4];
// 先排序
const sorted = arr.sort((a, b) => a - b);
const len = sorted.length;
let median;

if (len % 2 === 1) {
    // 奇数长度，直接取中间元素
    median = sorted[Math.floor(len / 2)];
} else {
    // 偶数长度，中间两个数取平均值
    const mid1 = sorted[len / 2 - 1];
    const mid2 = sorted[len / 2];
    median = (mid1 + mid2) / 2;
}
console.log(median); // 5
```
